PRODUCT LIST USING REACT PROPS

Aim:
To create a React application that passes product name and price as props
and displays four products.

How to run:
1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal in this folder.
4. Run: npm install
5. Run: npm run dev
6. Open the local URL shown in the terminal.

Files:
- index.html: Main HTML page
- package.json: Project dependencies and commands
- src/main.jsx: React entry point
- src/App.jsx: Product and App components
- src/style.css: Page styling

Concept:
The Product component receives name and price through props.
The App component passes values for four products.
